# Beanstalk v0.5.0

## Release Notes

- Add `beanstalk update --body` for atomically replacing a task's Markdown body.
- Add full-screen task details and selected-task navigation to the TUI.
- Add contextual TUI help and improve shortcut readability.
- Publish a project-maintained Homebrew tap at `kpb/tap`.

## Release Checklist

- [ ] Review the README and documentation.
- [ ] Confirm the working tree contains only intended changes.
- [ ] Run `gofmt -l .`, `go vet ./...`, and `go test ./...`.
- [ ] Commit the release-ready changes and push the commit to `main`.
- [ ] Create and push the `v0.5.0` tag:

  ```bash
  git tag v0.5.0
  git push origin v0.5.0
  ```

- [ ] Confirm the Release workflow succeeds and creates the GitHub release:

  ```bash
  gh run list --repo kpb/beanstalk --workflow Release --limit 1
  gh release view v0.5.0 --repo kpb/beanstalk
  ```

- [ ] Download a macOS archive and verify its checksum and build provenance:

  ```bash
  gh release download v0.5.0 --repo kpb/beanstalk \
    --pattern checksums.txt \
    --pattern beanstalk_0.5.0_darwin_arm64.tar.gz
  shasum -a 256 -c checksums.txt
  gh attestation verify beanstalk_0.5.0_darwin_arm64.tar.gz \
    --repo kpb/beanstalk \
    --signer-workflow kpb/beanstalk/.github/workflows/release.yml
  ```

- [ ] Verify the Homebrew formula has updated and installs the release:

  ```bash
  brew update
  brew upgrade beanstalk
  beanstalk version
  ```
