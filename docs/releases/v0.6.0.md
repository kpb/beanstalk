# Beanstalk v0.6.0

## Release Notes

- Improve split-pane browsing with a wider task pane, visible hierarchy guides on bean IDs, and compact aligned type and
  status columns. Correct the bug marker and status styling.
- Strengthen task-file integrity: make task creation atomic and durable, validate configured ID prefixes and update
  statuses, and roll back files from failed project initialization.
- Keep archived tasks read-only, sanitize task content before terminal output, and report the effective default priority
  in `create --json`.
- Document the Beans task-file schema, CLI JSON contracts, and update round-trip formatting semantics; add compatibility
  fixtures and tests.
