# Beanstalk v0.7.0

## Release Notes

- Search task IDs, titles, and Markdown bodies case-insensitively with `beanstalk search "text"`; use `--json` for scripts
  and `--all` to include archived tasks. Results exclude archived tasks by default.
- Press `/` in the TUI to search and browse matches, then Enter to navigate to a task or Esc to cancel. Search includes
  tasks hidden by collapsed hierarchy branches and follows the TUI's archive visibility setting.
- Add a Go 1.26 VS Code dev container for development.
- Correct split-pane status labels to distinct, aligned single-letter abbreviations.

The `beanstalk upgrade` command remains future work and is not part of this release.
